# OpenAI's ChatGPT logo

https://developers.openai.com/assets/siwc/sign-in-buttons/chatgpt-logo-white.svg (2026-10-26, sha256
`568ce2e8701934856aaafc0ed1c3d0300f6c2ff384d0ae743dd1dea08570e12c`).

It's OpenAI's trademark, not covered by Emmet's licenses. Emmet shows it only inside the "Continue with ChatGPT"
button, in the approved format of OpenAI's Sign in with ChatGPT UI/UX guidelines (TRADEMARKS.md, D-37).
