# Data

Hand-curated data the engine reads, added by the sessions that need it (plan section 05):

- `connections/`: the connector data: `ldcad-shadow.ldr`, converted from the LDCad Shadow Library (CC BY-SA 4.0,
  its own license in `connections/LICENSE.md`), and Emmet's overrides (`*.toml`). See `connections/README.md`.
- `synonyms.toml`: parts-search synonyms
- `techniques/`: technique snippets with docs (Apache-2.0)
- `ladder/`: rung prompts, reference models, and scoring config
