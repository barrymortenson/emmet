## Terms, re-read 2026-10-26

Nothing loses its basis; `scripts/terms-check` finds every recorded phrase.

- **Anthropic** ([legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)): "preinstalling or
  running Claude Code in your products" under the Commercial Terms (H-20), and the binary "must be installed and run
  as published by Anthropic". Sign-in "must complete through Anthropic's own flow". The
  [setup page](https://code.claude.com/docs/en/setup) publishes the native installer (`curl -fsSL
  https://claude.ai/install.sh | bash`, `irm https://claude.ai/install.ps1 | iex`), "You do not need to run as
  Administrator", a signed SHA-256 manifest per release, and Developer ID and Authenticode signatures by Anthropic.
  The [authentication page](https://code.claude.com/docs/en/authentication) documents `claude auth login` "in your
  shell" as a sign-in that skips the first-run prompt.
- **OpenAI**: Codex is Apache-2.0 ([repo](https://github.com/openai/codex)). OpenAI publishes a standalone installer
  for macOS and Windows (`curl -fsSL https://chatgpt.com/codex/install.sh | sh`, `powershell -ExecutionPolicy ByPass
  -c "irm https://chatgpt.com/codex/install.ps1 | iex"`), which checks each archive's SHA-256 and needs no Node.
  Its documented `CODEX_NON_INTERACTIVE` skips its prompts. [Pricing](https://learn.chatgpt.com/docs/pricing):
  Codex is "included in your ChatGPT Free, Go, Plus, Pro, Business, Edu, or Enterprise plan".
- **Google**: unchanged since 2026-10-25 (D-42). Antigravity has no `agy mcp add`; its
  [MCP page](https://antigravity.google/docs/mcp/) names `~/.gemini/config/mcp_config.json` (global) and
  `<workspace>/.agents/mcp_config.json` (that workspace only).

## Decisions (docs/decisions.md, 2026-10-26)

- Claude's sign-in runs `claude auth login` with no terminal and no new dependency: with stdin closed and no TTY it
  opens the browser itself on a `localhost` callback and exits when sign-in is done. If the browser can't reach the
  callback and shows a code, Emmet never touches the code: the sign-in window offers the Open Terminal card.
- Antigravity: Emmet writes `.agents/mcp_config.json` in the open project only (never `~/.gemini`), on a click.
