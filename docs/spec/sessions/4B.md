## Order of work

1. **The agent turn carries context and settings.** `UserTurn` gains the structured context (the selected ids, the
   view, a finding or a failed build with its file and line) and each adapter writes it into the message the CLI
   gets; the chat shows only the plain words. Model and effort per session: Claude Code's documented `--model` aliases
   and `--effort` levels (a change restarts the CLI with `--resume` before the next turn); Codex's `model/list` and
   `turn/start`'s `model` and `effort`.
2. **Sessions.** Per-project history (`.emmet/chat/sessions.json`: each session's agent, start, and title), resume
   after an app restart, the agent picker that starts a fresh conversation and keeps the old one (a divider), Start
   fresh, tokens used where the CLI reports them.
3. **Versions and the agent.** An automatic version before each turn that changes the sources (the sources are
   snapshotted when the turn starts and saved as a version once the first source changes), Undo turn (⌥⌘Z) restoring
   it, the `save_version` MCP tool, and the doctrine line to save a version before a risky change.
4. **emmet-bus complete.** `camera` (read or set the view) and `selection` (what the user picked) beside `highlight`,
   in `emmet mcp` for both the app's sessions and terminal agents; `docs/spec/bus.md`.
5. **Agent health.** A crash → Restart (resumes the session); not installed or signed out → the fix card in the dock;
   an untested version → a quiet note.
6. **The chat to the frozen design.** The dock's top (agent picker, plan badge, status with Stop and the time, Undo
   turn, History, Start fresh), the card that needs you or the latest line, History opening upward, the composer with
   the model and effort chip. Messages with safe markdown (no raw HTML), Thinking folded, tool cards from one table of
   plain-language summaries (`apps/desktop/src/summaries.ts`, product copy per `content.md`), file cards in words, three
   or more finished cards folded into one line, approval and question cards, pending redirects, the plan usage popover,
   the limit cards. The Checks drawer and the failed-build card drop file:line labels, excerpts, and tracebacks (they go
   to the agent). A virtualized list for long chats.
7. **Tips.** One tip at a time, at the first knob, the first finding, and the first export; seen tips kept per user in
   app data.
8. **Replay E2E** with both fake agents, the screenshots of every chat state, then Barry's rung 2 hand sessions and
   their scrubbed transcripts folded into `tests/replay/`.
