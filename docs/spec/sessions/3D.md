## Live check

Barry OK'd three live builds (2026-10-30): Claude Code 2.1.314 on his plan, with Emmet's `emmet` MCP server and the
new doctrine, in empty projects with no build settings, with only the prompt. Each read `rules`, then called `guide`
before its first draft, unprompted, and built with the new techniques:

| Prompt | Guides it read | Techniques it used | Result |
|---|---|---|---|
| Build a small blocky house | `blocky`, then `guide` for the settings | stepped_plank_roof, block_tree, stick_torch, door_frame, window_frame, wall_top_tie | 158 parts, 33 tool calls, 2.7 min; one step_size warning; `live-blocky-house.png` |
| Build a micro city block | `micro`, `micropolis` | micropolis_block, micro_tower, tower_crown, stepped_tower_setbacks, floor_band_bricks, micro_traffic, micro_tree_cluster | 223 parts, 36 calls, 2.2 min; no findings; `live-micro-city.png` |
| Build a red sports car | `guide` for the settings, then `vehicles` | racing_scale_base (with car wheels), quarter_tile_headlights, tail_lights, rear_spoiler | 118 parts, 59 calls, 5.5 min; no findings; `live-sports-car.png` |

What it changed: the blocky house stood small on a bare baseplate, because it read only the Blocky guide, and "the
model covers at most half its base" lives in the figure-scale and landscaping guides. So `guide` with no scale set
now returns figure scale's guide (the doctrine's default) with the style's, and the Blocky guide says a blocky model is
a scene whose ground is blocks too. The sports car has no windscreen; the Vehicles guide already says a cab's glass
lifts off, and that's left to the agent.
