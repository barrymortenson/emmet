## Approach

Tokens first (`apps/desktop/src/styles/tokens.css`), then components built only from tokens
(`docs/design/frozen/components.css`, one section per inventory entry, with each component's DOM shaped like the Radix
primitive 4A will use: roles and `data-state`), then every frozen screen composed from those components alone. The
frozen screens reuse 2A's real data (`docs/design/shared/data.js`, renders, part pictures) and take B's screens as
their starting list; A, B, and C stay as 2A left them, as the record.
