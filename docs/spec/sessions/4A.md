## Order of work

1. **Design system in the app.** `components.css` and `approved.css` from `docs/design/frozen/` into
   `apps/desktop/src/styles/` (the specimens' `data-show` rules left out), Radix primitives (D-29, section 06) behind
   small React components that emit the frozen markup, and `scripts/style-lint.mjs` (no raw colors or pixel sizes
   outside `tokens.css`; `approved.css` is OpenAI's own and exempt). The old `styles.css` goes.
2. **The shell.** The window (macOS overlay title bar; Windows without decorations, with the menu bar and caption
   buttons), the title row (project chip and its menu, the view switch), the viewer, the chat dock, the resizable
   separator, the options panel (state, Export, tabs); native menus on macOS; the keyboard map.
3. **The panel's tabs.** Options (build settings in `emmet.toml [build]` with Undo and Rebuild; knobs as drafts with
   Reset and Keep, Keep through `emmet params --write-default`), Checks (findings, It's fine → `[[check.allow]]`,
   Check it again, Ask agent to fix), Parts (the parts list with part pictures, availability, the Rebrickable
   credit), Steps (the tree from `build/steps.json`; a step shows the build up to it; a sub-assembly highlights every
   copy). Export menu and toast with Show in folder.
4. **Projects and versions.** New without a dialog into the projects folder (`Documents/Emmet` by default), as the
   Cottage or an empty baseplate; Open (a project folder, or an `.ldr`/`.mpd` file, which becomes an imported
   project); Open Recent. `emmet version save|list|restore|open` in emmet-core and the CLI; Save version (⌘S), the
   versions list, a version opened read-only to compare, Restore (saving the current state first), Open as new
   project.
5. **Trust and banners.** The read-only banner and Trust this project (D-27), offline, the old library, and the
   imported file's Make it parametric.
6. **First run.** Welcome; the library download in the host with progress, resume, and Try again; Python; 1F's agent
   setup restyled; the Cottage or a new model from a prompt. A debug-only library URL override, so E2E downloads from
   a local fixture server (ldraw-mini zipped) and never the real library.
7. **Settings and About.** Agent and model preference, projects folder, appearance, color names, viewer quality,
   updates (a stub until 6A), Install command line tool, Copy diagnostics; About with the versions, the attributions
   (LDraw.org and the part authors, Rebrickable, the LDCad Shadow Library, D-44), the disclaimer, the provider notice
   (D-37), and what Emmet connects to.
8. **E2E and visual baselines**, then the side-by-sides, the timed first run, and the warm start.
